# Estadisticas

## Gratis ahora

GitHub muestra estadisticas basicas del repositorio:

1. Abrir el repositorio en GitHub.
2. Entrar en `Insights`.
3. Entrar en `Traffic`.

Incluye visitantes, vistas, referentes y contenido popular. La limitacion importante es que GitHub conserva estos datos durante 14 dias.

## SEO gratis

Google Search Console es la mejor herramienta gratuita para saber:

- Que busquedas llevan gente a la revista.
- Que paginas indexa Google.
- Si hay problemas de rastreo.
- Cuantos clics e impresiones llegan desde Google.

Para usarla con GitHub Pages:

1. Ir a Google Search Console.
2. Anadir propiedad de tipo `URL prefix`.
3. Usar esta URL:

```text
https://100495807.github.io/el-garaje-de-hompa/
```

4. Elegir verificacion por etiqueta HTML.
5. Copiar el `content` de la etiqueta.
6. Anadirlo al layout de la web.

## Analytics mas completo

Opciones:

- Google Analytics 4: gratis, muy completo, menos privado.
- Cloudflare Web Analytics: gratis y bastante limpio, pero requiere configurar Cloudflare.
- Plausible / Fathom: mejores para privacidad, normalmente de pago.

Para no cargar la web con scripts antes de tiempo, lo ideal es empezar con GitHub Traffic + Search Console.
